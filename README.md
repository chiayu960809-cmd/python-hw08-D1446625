## 四、個人回答

### 問題一
為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？

**回答：**

因為 `"4"` 是字串，並不是可以直接進行除法計算的數字，所以需要先使用 `int()` 將它轉換成整數 `4`，才能正確計算每個人需要分攤多少費用。

### 問題二
如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？

**回答：**

如果先扣除 100 元折價券，餐費就會變成 1100 元，接著計算 10% 服務費為 110 元，因此應付總額是 1210 元。

但題目規定要先用原始餐費 1200 元計算服務費，再扣除折價券，所以正確的應付總額是 1220 元。兩者相差 10 元，是因為計算服務費的基準金額不同。
